## 📋 概述

**SelfBrain** 是一个本地运行的AI隐私保护层，通过**架构分片 + 动态加密**实现银行级数据安全，同时集成Memory Palace实现智能Token优化。

**核心定位**: "Your AI, Your Control" - 让企业完全掌控自己的AI使用。

---

## 🎯 核心创新（今日讨论成果）

### 1. 三MEMO协同架构 ⭐⭐⭐⭐⭐

```
SelfBrain-3B (总调度)
    ↓
Data Broker-0.5B (协调员)
    ↓
    ├─→ MEMO-Navigator-1.5B (导航员)
    │   └─ 记住Memory Palace完整地图
    │   └─ 持续微调，跟踪信息更新
    │
    └─→ MEMO-Cipher-1.5B (密码员)
        └─ 动态密码生成/解密
        └─ 时效性管理（5分钟过期）
```

**总参数**: 6.5B  
**本地运行**: RTX 4060 Ti 8GB 可运行

---

### 2. 动态密码系统（类银行U盾）

**关键特性**:
- ✅ 时效性：每个密码5分钟自动过期
- ✅ 会话隔离：同一数据不同会话→不同密码
- ✅ 分层前缀：L1_xxx / L2_xxx / L3_xxx
- ✅ 一次性使用：解密后立即销毁

**示例**:
```
原始: "$500M"
任务1 (16:35): → AMOUNT_C3D9_T1722240900
任务2 (16:40): → AMOUNT_E7F2_T1722241200 (不同!)
```

---

### 3. Memory Palace 深度集成

**分层权限**:
```
L1 (立体检索): 按任务动态分配
L2 (时序管理): 按任务动态分配  
L2.5 (实体图谱): 按任务动态分配
L2.7 (时序预测): 仅SelfBrain ⭐
L3 (原始归档): 仅SelfBrain ⭐⭐⭐
```

**Token优化**:
- 简单查询: 只访问L1 (50 tokens)
- 中等查询: L1+L2 (200 tokens)
- 复杂查询: SelfBrain主导 (300 tokens)
- vs 传统: 每次5000+ tokens

**节约**: 70-80%

---

### 4. 可视化Dashboard（四层安全）

用户可实时看到:
1. **Layer 1**: 动态密码状态（剩余有效期、密码本）
2. **Layer 2**: 分层权限（哪个模型访问了哪层）
3. **Layer 3**: 完整保存（原始数据安全存储）
4. **Layer 4**: 审计日志（所有访问记录）

**用户感知**: "我亲眼看到数据被分片、加密、分发" → 建立信任

## 🎯 核心工作流程

```
用户任务
    ↓
SelfBrain-3B 分析任务
    ↓
Data Broker 协调查询
    ↓
    ├─→ MEMO-Navigator: "数据在哪里?"
    │   └─ 返回: L1/finance/revenue/2026_Q3
    ↓
从Memory Palace提取原始数据
    ↓
    └─→ MEMO-Cipher: "请加密"
        └─ 生成动态密码本
        └─ 加密数据
    ↓
发送加密数据给GPT-4
    ↓
GPT-4分析 (看到的是密码)
    ↓
返回加密形式的回复
    ↓
    └─→ MEMO-Cipher: "请解密"
        └─ 验证会话
        └─ 解密
        └─ 销毁密码本
    ↓
SelfBrain整合结果
    ↓
返回给用户 (明文)
```

**总延迟**: < 200ms (MEMO处理时间)
