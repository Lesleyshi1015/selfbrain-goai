Privacy Guardian — Team Leader

总调度 · 任务发布 · 完整度评估 · 结果整合

Privacy Guardian 是整个7-Agent系统的"大脑"。作为 Team Leader，它接收用户请求、分析任务复杂度、发布子任务到共享黑板、轮番调度Workers、评估结果完整度，最终整合输出。

核心职责流程：

1. 请求接收与分析
   - 意图识别
   - 敏感度评估
   - 复杂度分级

2. 任务发布到黑板
   - 写入 task
   - 写入 query
   - 初始化 results

3. Worker 轮番调度
   - 按需调用 Memory Navigator
   - 按需调用 Cipher Generator
   - 按需调用 Data Coordinator
   - 按需调用 Policy Enforcer
   - 按需调用 Audit Logger
   - 按需调用 Validator

4. 完整度评估
   - 检查黑板 completeness
   - 缺失则补充调用

5. 结果整合输出
   - 融合多源数据
   - 生成最终响应

为什么需要3B参数：

| 决策能力 | 1.5B | 3B | 差距 |
|---------|------|-----|------|
| 意图理解准确率 | 82% | 95% | +13% |
| Worker路由准确率 | 78% | 94% | +16% |
| 完整度评估准确率 | 70% | 90% | +20% |

渐进式处理策略：

简单查询（50-100ms）：
User → Privacy Guardian → Memory Navigator → 返回

复杂分析（2-5秒）：
User → Privacy Guardian → 发布黑板
→ Memory Navigator + Cipher Generator + Data Coordinator
→ Policy Enforcer（权限验证）
→ Cipher（加密）→ GPT-4（分析）→ Cipher（解密）
→ Validator（6维核查）→ Audit Logger（记录）
→ Privacy Guardian（整合）→ 返回

- Worker路由准确率：94%
- 完整度评估准确率：90%
