Memory Navigator — 记忆导航员

Memory Adapter 通用适配器层 · 五层检索

Memory Navigator 是SelfBrain的核心Worker，负责通过 Memory Adapter 通用接口访问任意记忆系统后端。不依赖任何特定记忆系统——SelfBrain是真正的通用AgentInfra。

Memory Adapter 四层架构：

SimpleFileAdapter ✅ 开源
- 本地文件，开箱即用
- 零依赖，个人用户首选

VectorDBAdapter ✅ 开源
- ChromaDB / Milvus
- 技术用户，已有向量库

MemoryPalaceAdapter 🔒 闭源SDK
- Memory Palace五层架构
- 企业级，高级功能

CustomAdapter ✅ 开源模板
- 用户自定义
- 任意后端

四种适配器对比：

| 适配器 | 定位 | 层级支持 | 适用人群 |
|-------|------|---------|---------|
| SimpleFileAdapter | 本地文件 | 自定义目录 | 个人用户 |
| VectorDBAdapter | ChromaDB | 自定义 | 技术用户 |
| MemoryPalaceAdapter | 五层架构 | L1-L3 | 企业用户 |
| CustomAdapter | 自定义 | 任意 | 开发者 |

核心能力与性能：

| 能力 | 性能目标 | 示例 |
|------|---------|------|
| 适配器路由 | <5ms | vector_db → VectorDBAdapter |
| 地图维护 | 准确率>98% | L2/finance → 实际路径 |
| 路径查询 | <50ms | "Q3营收" → L1/finance/revenue |
| 增量学习 | 每1000次微调 | 新增数据自动学习 |

三级缓存架构：
- L1缓存（内存）：1000条热点，命中率60%，<1ms
- L2缓存（Redis）：10000条历史，命中率30%，<10ms
- L3搜索（向量）：完整地图，命中率100%，<50ms

关键指标：
- SimpleFile延迟：<20ms
- VectorDB延迟：<50ms
- MemoryPalace延迟：<100ms
- 路径准确率：>95%

核心价值：
- 零门槛：SimpleFileAdapter开箱即用
- 灵活：配置切换无需改代码
- 可扩展：社区贡献新适配器
